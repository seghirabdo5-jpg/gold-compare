# موقع مقارنة أسعار الذهب والمجوهرات (السعودية والخليج)

موقع Next.js عربي (RTL) لمقارنة أسعار الذهب ومتاجر المجوهرات، مبني ليعمل من الهاتف بالكامل عبر GitHub + Vercel.

---

## 1. قائمة الملفات المهمة ووظيفتها

| الملف | الوظيفة |
|---|---|
| `config/site.config.ts` | **أهم ملف في المشروع.** اسم الموقع، الدومين، روابط Affiliate، إعدادات Google Analytics و Search Console، إعدادات مصدر سعر الذهب |
| `data/stores.json` | بيانات المتاجر (الاسم، المنتجات، المدن، الفروع). عدّله لإضافة/تعديل متجر |
| `content/blog/*.md` | مقالات المدونة. كل ملف = مقال واحد |
| `lib/goldPrice.ts` | منطق جلب سعر الذهب من API. يعرض رسالة "غير متوفر" حتى تربط API حقيقي |
| `lib/stores.ts` | دوال قراءة بيانات المتاجر |
| `lib/blog.ts` | دوال قراءة مقالات المدونة |
| `app/page.tsx` | الصفحة الرئيسية |
| `app/gold-calculator/` | صفحة حاسبة الذهب |
| `app/compare/page.tsx` | صفحة مقارنة المتاجر |
| `app/stores/[slug]/page.tsx` | صفحة كل متجر (تُبنى تلقائيًا من `stores.json`) |
| `app/near-me/` | صفحة أقرب متجر (تستخدم GPS المتصفح فقط، لا تُخزَّن البيانات) |
| `app/blog/` | صفحة المدونة الرئيسية وصفحة كل مقال |
| `app/go/[slug]/page.tsx` | رابط تحويل سريع لحملات إعلانية، مثل `/go/zomorod` |
| `app/about`, `contact`, `privacy`, `terms`, `affiliate-disclosure`, `gold-price-sources` | صفحات الثقة المطلوبة |
| `app/sitemap.ts` / `app/robots.ts` | ملفات SEO تلقائية |
| `components/Header.tsx` / `Footer.tsx` | القائمة والتذييل |
| `components/GoldPriceCard.tsx` | بطاقة عرض سعر الذهب |
| `components/StoreCard.tsx` | بطاقة عرض متجر |

## 2. أين أضيف رابط Affiliate؟

افتح `config/site.config.ts` وابحث عن `affiliateLinks`، وضع الرابط أمام اسم المتجر:

```ts
export const affiliateLinks: Record<string, string> = {
  zomorod: "https://your-affiliate-link.com",
  alrabsh: "",
  ...
};
```

بمجرد إضافة الرابط، سيظهر زر "زيارة الموقع" تلقائيًا في بطاقة المتجر، صفحة المتجر، وصفحة `/go/[slug]`. إن تركته فارغًا، لن يظهر أي رابط فارغ للمستخدم.

## 3. أين أغيّر اسم الموقع؟

`config/site.config.ts` → `siteConfig.name` و `siteConfig.description` و `siteConfig.url` (بعد ربط الدومين).

## 4. أين أضيف/أغيّر سعر الذهب أو الـ API؟

`config/site.config.ts` → `goldPriceConfig`:
- ضع `apiUrl` و `apiKey` الخاصين بمزود بيانات حقيقي (مثل GoldAPI.io).
- غيّر `isLive` إلى `true`.
- افتح `lib/goldPrice.ts` وعدّل الجزء الذي يحوّل استجابة الـ API حسب شكلها الفعلي (موضّح بتعليقات داخل الملف).

قبل ربط API، سيعرض الموقع دائمًا: "سيتم تحديث الأسعار عند توفر مصدر البيانات" بدل أرقام وهمية.

## 5. أين أضيف متجرًا جديدًا؟

افتح `data/stores.json`، انسخ أحد كائنات المتاجر الموجودة، وغيّر:
`slug` (يُستخدم في الرابط)، `name`، `shortDescription`، `products`، `features`، `cities`، `branches`.
صفحة المتجر وبطاقته ستُبنى تلقائيًا — لا حاجة لإنشاء صفحة جديدة يدويًا.

## 6. أين أضيف مقالًا جديدًا؟

أنشئ ملف `.md` جديد داخل `content/blog/` بنفس تنسيق الملفات الموجودة (يبدأ بـ `title` و `description` و `date` و `intent` بين `---`)، ثم اكتب المحتوى بصيغة Markdown تحته. سيظهر تلقائيًا في `/blog`.

## 7. أين أغيّر Google Analytics؟

`config/site.config.ts` → `googleAnalyticsId = "G-XXXXXXXXXX"`.

## 8. أين أضع كود تحقق Google Search Console؟

`config/site.config.ts` → `googleSiteVerification = "الكود هنا"` (من إعدادات الملكية في Search Console، اختر طريقة HTML tag وانسخ الكود فقط بدون وسم HTML).

## 9. أين أضع Google Ads Conversion ID؟

`config/site.config.ts` → `googleAdsConversionId` (جاهز للاستخدام لاحقًا عند إضافة كود التحويل).

## 10. طريقة التشغيل والنشر من هاتف Android فقط (خطوة بخطوة)

### الفكرة العامة
GitHub = مكان تخزين الكود. Vercel = المنصة التي "تُشغّل" الموقع وتعطيك رابطًا مجانيًا، وتربطه بـ GitHub تلقائيًا (كل تحديث في GitHub يُحدّث الموقع المباشر خلال دقائق).

**لماذا Vercel وليس منصة أخرى؟** لأنها الأنسب لمشاريع Next.js تحديدًا (الشركة صانعة Next.js)، النشر تلقائي عند كل تعديل، ولوحة التحكم تعمل جيدًا من متصفح الهاتف. بديل أبسط قليلًا إن أردت لاحقًا: Netlify (يعمل بنفس الطريقة تقريبًا).

### الخطوات

1. **إنشاء حساب GitHub**
   من متصفح الهاتف (Chrome) اذهب إلى github.com → Sign up → أدخل بريدك الإلكتروني وكلمة مرور → أكمل التسجيل.

2. **إنشاء Repository جديد**
   بعد تسجيل الدخول: اضغط "+" أعلى الصفحة → New repository → اكتب اسمًا مثل `gold-compare` → اختر Public → Create repository.

3. **رفع ملفات المشروع من الهاتف**
   في صفحة الـ Repository الفارغة: اضغط "uploading an existing file". يمكنك رفع الملفات كمجلد مضغوط (zip) عبر أي مدير ملفات على الهاتف، لكن GitHub على المتصفح لا يفك الضغط تلقائيًا — الطريقة الأسهل من الجوال:
   - حمّل تطبيق **Working Copy** (iOS) غير متاح على أندرويد، لذلك على أندرويد الأسهل هو تطبيق **"GitHub" الرسمي** لرفع/تعديل ملفات نصية مباشرة، أو استخدام تطبيق **Termux** لرفع المشروع كاملًا عبر أوامر git (للمستخدم المتقدم قليلًا).
   - **الطريقة الأبسط لمبتدئ:** ثبّت تطبيق **GitHub** من Google Play → سجّل دخولك → افتح الـ Repository → لن تستطيع رفع مجلد كامل بضغطة واحدة من التطبيق، لذلك الخيار العملي الموصى به هو:
     **استخدم Vercel مباشرة لاستيراد المشروع بدل الرفع اليدوي لكل ملف** (موضّح بالخطوة التالية) — فبمجرد ربط GitHub بـ Vercel، يمكنك لاحقًا تعديل الملفات النصية (مثل `site.config.ts` أو مقالات `.md`) مباشرة من متصفح الهاتف عبر واجهة GitHub نفسها (زر القلم ✏️ على أي ملف)، دون الحاجة لرفع المشروع بالكامل يدويًا كل مرة.

   > ملاحظة عملية: أفضل طريقة لرفع المشروع بالكامل أول مرة من الجوال هي عبر تطبيق **Termux** (متجر F-Droid أو Google Play) بتنفيذ أوامر git البسيطة، أو أن تطلب من شخص لديه كمبيوتر لمرة واحدة فقط لعمل أول "رفعة" (push)، وبعدها كل التعديلات (نصوص، أسعار، مقالات، روابط Affiliate) تتم من الهاتف مباشرة عبر تعديل الملفات في واجهة GitHub على المتصفح.

4. **ربط المشروع بـ Vercel**
   من متصفح الهاتف: vercel.com → Sign up → اختر "Continue with GitHub" → اسمح بالصلاحيات.
   بعد الدخول: اضغط "Add New Project" → اختر الـ Repository الذي رفعت إليه المشروع (`gold-compare`) → اضغط Import → اترك الإعدادات الافتراضية (Vercel يتعرف على Next.js تلقائيًا) → اضغط Deploy.
   خلال دقيقة إلى دقيقتين سيعطيك رابطًا مجانيًا مثل: `gold-compare.vercel.app`.

5. **تعديل النصوص أو الروابط من الهاتف مستقبلًا**
   افتح متصفح الهاتف → github.com → افتح الـ Repository → افتح الملف الذي تريد تعديله (مثلًا `config/site.config.ts`) → اضغط أيقونة القلم ✏️ (Edit) → عدّل النص → في الأسفل اضغط "Commit changes".
   خلال دقائق سيقوم Vercel تلقائيًا بتحديث الموقع المباشر بالتعديل الجديد — لا حاجة لأي خطوة إضافية.

6. **إضافة رابط Affiliate من الهاتف**
   افتح `config/site.config.ts` على GitHub من المتصفح → عدّل القيمة أمام اسم المتجر داخل `affiliateLinks` → Commit changes.

7. **إضافة مقال جديد من الهاتف**
   داخل مجلد `content/blog` على GitHub → اضغط "Add file" → "Create new file" → سمِّه مثلًا `article-name.md` → الصق المحتوى بنفس تنسيق المقالات الموجودة → Commit changes.

8. **ربط دومين خاص لاحقًا**
   بعد شراء دومين (من أي مزود مثل GoDaddy أو Namecheap): في لوحة Vercel → Project → Settings → Domains → أضف الدومين → سيعطيك Vercel سجلات DNS (CNAME/A) → أدخلها في لوحة تحكم الدومين لديك → انتظر انتشار DNS (قد يأخذ حتى 24 ساعة).
   بعد ذلك عدّل `siteConfig.url` في `site.config.ts` ليطابق الدومين الجديد، وأضف نفس الدومين في Google Search Console.

9. **تحديث الموقع مستقبلًا**
   أي تعديل على أي ملف داخل GitHub (نص، رابط، مقال، متجر جديد) ينشر نفسه تلقائيًا على Vercel خلال دقائق. لا حاجة لأي أمر يدوي.

## 11. ما لم يُبنَ بعد (يحتاج بيانات حقيقية منك)

- لا توجد أسعار ذهب حقيقية معروضة (تحتاج ربط API — راجع القسم 4).
- بيانات المتاجر (الموقع، الهاتف، الفروع، الإحداثيات) فارغة عمدًا لتجنب معلومات غير دقيقة — أضفها في `data/stores.json` بمجرد التأكد منها.
- صفحات الدول الخليجية الأخرى (الإمارات، الكويت...) والميزات المستقبلية (الفضة، حاسبة الزكاة، إشعارات الأسعار) لم تُبنَ بعد بحسب طلبك، لكن بنية المشروع (Config + JSON + مقالات Markdown) مصممة لإضافتها بسهولة لاحقًا دون إعادة بناء الموقع.
